# bubble-game

An early-stage balloon-popping game project, with ideas for playing it using hand tracking.

## What's in this repo

- `BalloonPopGame-main/` is the game folder.
- `playagain.html` is a "game over" screen with a congratulations message and a **Play Again** button that sends the player back to the game page. It has an animated gradient background and balloons floating behind the panel, all in plain HTML, CSS and a little JavaScript.
- `text.txt` is a scratch file of Python imports for a hand-tracking version of the game.

## Tech

From the code in the repo:

- **Web page:** HTML, CSS, JavaScript
- **Planned game and vision stack:** Python, pygame, OpenCV (`cv2`), NumPy, and cvzone's `HandDetector` for webcam hand tracking, with Flask for a web interface
